Calculus in eli5-style simple summary words

1 Suppose you are sailing ⛵️ across the pacific ocean to a tropical island 🏝️. 2 During the journey you recorded 📝 the hourly speed, daily distance, and total distance data. At the destination if you want to know the distance traveled you can simply refer to the distance log. But what if distance info was not recorded or lost, in that case you’d have to use speed-time data to calculate the distance. 3 What this means is: ➡️ If you have distance data, you can simply subtract numbers - easy! 😎 ➡️ If you only have speed data, then you have to accumulate areas - hard! 💦 Calculus techniques give you a math shortcut to find the easy solution when you only have the hard data. ✅ With calculus, area is simply difference. ✅ And hard is actually easy. 4 For example, if you have the speed-time function, calculus techniques give you a shortcut to both acceleration-time function and distance-time function. If you know one, all the others can be derived.
